### What I'm building

**[Renovia](https://wishyasin.github.io/renovia/)** · a mobile platform for urban transformation (*kentsel dönüşüm*) in Turkey

Owners of earthquake-risk buildings usually find a contractor through word of mouth and sign without being able to compare offers. Renovia lets them list their building, receive offers from verified contractors and compare them side by side.

- Flutter app for iOS and Android, Node.js + TypeScript API, PostgreSQL with PostGIS, Redis
- Ownership check for each listing: title deed upload, automated risk signals (reused images, name mismatch, already claimed units) and admin review
- Contractor license verification, offer comparison, in-app chat and meeting planning, project progress tracking
- Admin panel with two-factor login and moderation tools
- Turkish and English, with tests on both the API and the app

The source code is private for now while the product gets ready for launch.
